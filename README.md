## > About The Course

This repository contains the laboratory outputs and hands-on activities for **CPE 010 (Data Structures and Algorithms)**. The course focuses on solving computational problems using fundamental data structures, analyzing algorithmic efficiency (time and space complexity), and implementing optimized software solutions in C++.

## > Laboratory Activities

### >> [Prelim Period](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM)

- [**Hands-on Activity 1.1 Basic C++ Programming**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM/HOA1.1)
  * *Topics Covered:* C++ syntax, basic functions, input/output, using pointers, and setting up the IDE.
- [**Hands-on Activity 2.1 Arrays, Pointers and Dynamic Memory Allocation**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM/HOA2.1)
  * *Topics Covered:* Array operations, pointer arithmetic, and using new and delete for dynamic memory allocation.
- [**Hands-on Activity 3.1 Linked Lists**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM/HOA3.1)
  * *Topics Covered:* Creating nodes, inserting, deleting, and traversing singly, doubly, and circular linked lists.
- [**Hands-on Activity 4.1 Stacks**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM/HOA4.1)
  * *Topics Covered:* LIFO logic, implementing push, pop, and peek using arrays and linked lists.
- [**Hands-on Activity 5.1 Queues**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/PRELIM/HOA5.1)
  * *Topics Covered:* FIFO logic, enqueue and dequeue operations, linear queues, circular queues, and priority queues.

---

### >> [Midterm Period]()

- [**Hands-on Activity 6.1 Searching Techniques**]()
  * *Topics Covered:* Linear search, binary search, loop-based vs. recursive search methods, and search efficiency.
- [**Hands-on Activity 7.1 Sorting Algorithms Pt1**]()
  * *Topics Covered:* Basic sorting methods like Bubble Sort, Selection Sort, and Insertion Sort, plus comparing their performance.
- [**Hands-on Activity 8.1 Sorting Algorithms Pt2**]()
  * *Topics Covered:* Advanced sorting methods like Merge Sort, Quick Sort, and Heap Sort using divide-and-conquer.
- [**Hands-on Activity 9.1 Tree ADT**]()
  * *Topics Covered:* Binary Search Trees (BST), adding/deleting nodes, searching, and doing in-order, pre-order, and post-order traversals.

---

### >> [Finals Period](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/FINALS)

- [**Hands-on Activity 10.1 Graphs**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/FINALS/HOA10.1)
  * *Topics Covered:* Storing graphs using adjacency matrices and adjacency lists, directed vs. undirected graphs, and BFS/DFS traversals.
- [**Hands-on Activity 11.1 Basic Algorithm Analysis**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/FINALS/HOA11.1)
  * *Topics Covered:* Big-O, Big-Omega, and Big-Theta notation, and figuring out time and space complexity like O(1), O(n), and O(n^2).
- [**Hands-on Activity 12.1 Algorithmic Strategies**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/FINALS/HOA12.1)
  * *Topics Covered:* Problem-solving techniques including divide-and-conquer, greedy algorithms, dynamic programming, and backtracking.
- [**Hands-on Activity 13.1 Parallel Algorithms and Multithreading**](https://github.com/Obiascpe/CPE010-CPE21S1---Data-Structures-and-Algorithms---OBIAS/tree/main/FINALS/HOA13.1)
  * *Topics Covered:* Multithreading basics, splitting tasks across threads, managing concurrency, and measuring speedup.
- [**Hands-on Activity 14.1 Algorithm Complexity**]()
  * *Topics Covered:* Timing code execution manually, testing algorithms against different dataset sizes, and checking if real runtimes match theoretical Big-O.
